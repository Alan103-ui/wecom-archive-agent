私有化独立部署 · 年费模式 功能增补方案

wecom-archive-agent — 每家客户独立私有化部署、按年 License 收费 — 2026-08-18

一、路线确认与架构影响

选定"每家独立私有化部署 + 按年收费"后，相对通用 SaaS 路线有两点重大简化，也有两点必须补强：

可省掉的（不用做）：多租户隔离（每实例即一客户）、用量计量与在线计费、集中式账号体系。
必须补强的（私有化年费特有）：① License 授权与年审（收费基石）；② 一键部署 + 离线安装 + 自助运维（降低每家交付成本）；③ 合规与脱敏（企微存档强监管）；④ 远程诊断与升级通道（年费维保的支撑）。

二、交付必备功能（不做不能卖）

功能模块为什么私有化年费必须做具体要增加的能力
License 授权系统按年收费的收费基石，必须能签发、激活、到期管控机器指纹（CPU/主板/网卡）、离线激活（request→license 文件）、有效期校验、模块授权、防篡改签名、到期提醒与降级
一键部署 + 离线安装每家都要装，交付成本必须压到最低Docker Compose 模板、离线镜像包（tar 导出无需公网）、自动初始化库与种子、部署向导、升级脚本（含 DB 迁移与回滚）
数据库升级 PGSQLite 不适合生产并发与备份PostgreSQL 引擎、JSONB、向量检索、自动备份与一键恢复脚本
客户自助运维后台年费维保无法每家都人工盯系统状态看板（服务/资源）、日志下载、License 状态与续费入口、备份/恢复操作、版本与升级通道
合规与脱敏企微会话存档属强监管，客户法务必查员工知情告知存证、敏感字段脱敏展示/落库、留存期与自动清理、操作审计日志、证据链完整性
安全加固私有化环境也常被攻，且影响续费首次启动强制随机密钥、密码策略与强制改密、登录失败锁定、操作审计、可选 HTTPS/反代模板
远程支持与诊断年费含维保，需低成本远程排障脱敏诊断报告导出、可选远程协助通道（客户授权）、版本遥测（客户同意）
模型私有化与降本外部大模型按量计费会吃光年费利润本地模型可选（Ollama/私有部署）、模型路由（按场景选模型）、结果缓存去重、离线模型包

三、产品增值功能（提升年费价值、可涨价）

下面这些不是"卖得出去"的门槛，但决定了年费能定多高、续费率多好，是和竞品拉开差距的地方：

功能价值点建议增加的能力
行业模板可配置不同客户业务字段不同，固定 10 类不够用客户自定义字段/规则、模板导入导出、模板版本管理
处置闭环与 SOP当前只预警不闭环，客户要"处理掉"处置流程、工单流转、处置率/响应时效统计、回执确认
数据洞察报表管理层要"看趋势"而非只看列表质检报表、风险趋势、对话/销售分析、Excel/PDF 导出
全文检索私有化客户数据量大，找消息是刚需跨消息/抽取/附件的结构化检索与高亮
移动端 / 管理 App管理层移动查看预警H5 适配或轻量 App、预警推送
知识库 / 自定义词库提升抽取准确率（客户专属术语）客户词库管理、抽取反馈纠错闭环
内部系统集成私有化环境内要打通已有系统与客户 OA / HR / CRM 对接、Webhook 出
白标大客户要换 LOGO / 名称品牌名、LOGO、配色可配置
帮助与培训降低私有化交付后的支持量内置帮助中心、操作指引、视频/文档

四、年费模式运营支撑（商务侧）

  • License 生命周期管理：生成→激活→运行中→临期（提前 30/15/7 天提醒）→到期（功能降级或只读）→续费→新 License。
  • 版本通道：稳定版（客户生产用）与尝鲜版分离，升级由客户在运维后台一键触发，厂商推送离线升级包。
  • 维保 SLA：年费含远程支持响应时效（如工作日 4 小时响应），重大 bug 走紧急离线补丁。
  • 报价结构建议：首年 = 软件授权 + 实施部署费；续年 = 年费（含维保+升级）。大模型外部调用费可单列或包干。

五、优先级与节奏（相对原方案调整）

取消/降级：多租户隔离、SaaS 在线计费计量（本路线不需）。
Phase A（0–2 月，能交付第一家）：License 系统 + Docker 离线部署 + PostgreSQL + 安全加固 + 基础运维后台 + 合规脱敏。
Phase B（2–4 月，可规模化复制）：远程诊断 + 升级通道 + 模型私有化可选 + 自助运维完善 + 行业模板可配置。
Phase C（4–8 月，提客单价）：处置闭环 + 数据洞察报表 + 全文检索 + 移动端 + 白标 + 内部集成。
本方案基于 wecom-archive-agent 全量代码审计结论，针对"私有化独立部署 + 按年收费"路线裁剪。相较通用 SaaS 方案，已剔除多租户与在线计费，强化 License / 部署运维 / 合规 / 远程诊断四类私有化刚需。模块工作量可在立项后细化拆解。
